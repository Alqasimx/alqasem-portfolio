# ALQASEM AL-AHDAL — Personal Portfolio

موقع شخصي وسيرة ذاتية تفاعلية للقاسم إبراهيم الأهدل، مهندس أمن سيبراني من عدن، اليمن.

## عن الموقع

واجهة عربية متجاوبة بهوية بصرية أصلية مستوحاة من بيئات الأمن السيبراني وواجهات المختبرات الرقمية. يعرض الموقع المسار الأكاديمي والمهني، المشاريع، الأبحاث، المهارات، الشهادات، وإحصاءات TryHackMe.

## الأقسام

- نبذة مهنية وتواصل مباشر.
- الخبرة الحالية في TEAM WORK SMART LTD.
- التدريب والزيارات التوعوية للمدارس.
- التعليم ومشروع التخرج Pentest Toolbox.
- المشاريع التقنية مع مرشحات حسب المجال.
- بحث Cloud Technology and Cybersecurity.
- المهارات والأدوات الأمنية.
- الشهادات الحضورية والدورات المهنية.
- ملف TryHackMe وإحصاءاته.

## التقنيات

- HTML5
- CSS3

## التشغيل محليًا

يمكن تشغيل الموقع مباشرة بفتح `index.html` أو باستخدام أي خادم ملفات ثابت، مثل:

```bash
python3 -m http.server 3000
```

ثم فتح `http://localhost:3000`.
