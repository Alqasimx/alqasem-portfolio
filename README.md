# ALQASEM AL-AHDAL — Personal Portfolio

موقع شخصي وسيرة ذاتية تفاعلية للقاسم إبراهيم الأهدل، مهندس أمن سيبراني من عدن، اليمن.

## عن الموقع

واجهة عربية متجاوبة بتصميم كلاسيكي واضح يركز على الأمن الدفاعي والشبكات ومراقبة الأنظمة. يعرض الموقع المسار الأكاديمي والمهني، المشاريع، الأبحاث، المهارات الأساسية، الشهادات المهمة، الهوايات، وملف TryHackMe على مستوى اليمن.

## الأقسام

- نبذة مهنية وتواصل مباشر.
- الخبرة الحالية في TEAM WORK SMART LTD.
- التدريب والزيارات التوعوية للمدارس.
- التعليم ومشروع التخرج Pentest Toolbox.
- المشاريع التقنية، بما فيها منصة وصال للعقارات.
- بحث Cloud Technology and Cybersecurity.
- المهارات الأساسية في الأمن الدفاعي وSOC والشبكات وأمن الويب.
- الشهادات الحضورية والدورات المهنية الأهم.
- الهوايات والاهتمامات العملية.
- ملف TryHackMe مع ترتيب اليمن فقط.
