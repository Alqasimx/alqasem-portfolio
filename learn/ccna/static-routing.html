Static Routing

فهم فكرة المسار الثابت وكيفية إضافته إلى جدول التوجيه.

الفكرة

المسار الثابت يحدد للشبكة وجهة معروفة وnext hop محدد. يناسب البيئات الصغيرة أو المسارات التي تحتاج تحكمًا صريحًا.

Router(config)# ip route 192.168.20.0 255.255.255.0 10.0.0.2
Router# show ip route
Router# show ip route static
تأكد من صحة next hop ووجود مسار عودة قبل اختبار الاتصال بين الشبكات.
